# 게임 진행 흐름 정리 (2026-09-15)

> 사용자가 정리한 전체 게임 진행 순서와, 현재 구현 상태를 대조한 문서.
> 이 저장소를 보는 협업자를 위한 공유 메모 — 기획 확정 문서는 아니고, 다음 작업
> 우선순위를 잡기 위한 갭 분석이다.

## 의도한 전체 흐름

```
메인 인트로
  → 캐릭터들이 플레이어에게 세계관 설명
  → 캐릭터 하나하나 들어가 보고 대화 후 캐릭터 선택 (이나리는 구현 안 함)
  → 메인 페이즈 (인게임 전투)
  → 보스전 직전 대화
  → 보스전
  → 게임 종료
```

## 현재 구현 상태 대조

| # | 단계 | 상태 | 비고 |
|---|---|---|---|
| 1 | 메인 인트로 | ✅ 완료 | `IntroScene.unity` — 타이틀 + 시작 버튼. PR #21(신설, 협업자), PR #22(스타일링) |
| 2 | 캐릭터들이 세계관 설명 | ❌ 미구현 | 지금 `IntroScene`엔 이 파트가 없음. 별도 대화/컷씬 단계로 추가 필요 |
| 3 | 캐릭터 하나하나 들어가 대화 후 선택 | ⚠️ 부분 구현 | 지금은 캐릭터 선택 화면에서 카드 하나를 클릭하면 **그 캐릭터의 호감도 대화 #1이 바로 뜨고 런이 시작**됨(`GameManager.StartRun`). "여러 캐릭터를 미리 둘러보고 대화해본 뒤 최종 선택"하는 **탐색형 흐름은 없음** — 선택과 동시에 런이 확정되는 구조라 되돌릴 수 없음. 이나리는 기획대로 잠금 상태 유지(아트 대기, 미구현) |
| 4 | 메인 페이즈(인게임) | ✅ 완료 | `GameScene.unity` |
| 5 | 보스전 직전 대화 | ❌ 미구현 | 원 기획서 "호감도 대화 #2"(Should 우선순위)에 해당. 코드/씬 어디에도 아직 없음 |
| 6 | 보스전 | ✅ 완료 | `BossScene.unity` — PR #14(협업자 신설) + PR #19(버그 수정/정리, 이번 세션) |
| 7 | 게임 종료(결과 화면) | ✅ 완료 | `ResultScene.unity` |

## 남은 작업 (우선순위 논의 필요)

1. **세계관 설명 단계 (2번)** — `IntroScene` 뒤에 이어지는 새 단계. 대화형인지 컷씬인지, 캐릭터별로 다른 설명인지 공통 설명인지부터 정해야 함
2. **캐릭터 탐색→선택 흐름 (3번 확장)** — 지금의 "클릭=즉시 런 시작" 구조를 "미리보기 대화 → 최종 선택" 구조로 바꿔야 해서, `GameManager.StartRun`/캐릭터 선택 UI 쪽을 다시 설계해야 함. 세 가지 중 구조 변경 폭이 가장 큼
3. **보스전 직전 대화 (5번, 호감도 대화 #2)** — 원 기획서에 이미 설계 방향은 있음(같은 방식, 선택지→스탯 버프). `GameManager.EnterBossFight()` 직전에 끼워 넣는 형태가 될 것
